# ♟️ Sistema de Xadrez em Java

Este é um projeto desenvolvido em **Java puro**, com o objetivo de **simular uma partida completa de xadrez diretamente no console**.  
O sistema foi implementado de forma **orientada a objetos**, seguindo boas práticas de programação e cobrindo **todas as regras oficiais do xadrez**, incluindo movimentos especiais.

---

## 🚀 Funcionalidades

✅ Exibição do **tabuleiro no console**, com peças e cores  
✅ Controle de **turnos alternados** (brancas e pretas)  
✅ Validação completa dos movimentos possíveis de cada peça  
✅ Detecção de **xeque** e **xeque-mate**  
✅ Implementação dos **movimentos especiais**:
- **Roque (Castling)**
- **En Passant**
- **Promoção de Peão**

✅ Tratamento de exceções e mensagens claras ao usuário  
✅ Sistema modular e fácil de manter

## 🧠 Conceitos aplicados

- **Programação Orientada a Objetos (POO)**  
  - Encapsulamento  
  - Herança  
  - Polimorfismo  
  - Abstração  

- **Manipulação de matrizes** para representar o tabuleiro  
- **Validação de regras** do jogo com lógica condicional e controle de fluxo  
- **Interação no console**, simulando uma partida real por meio de coordenadas (ex: `e2` → `e4`)

---

## 🎮 Como jogar

1. **Execute o programa principal** (`Program.java` ou equivalente).
2. O tabuleiro será exibido no console.
3. Em cada turno, digite:
   - A **posição de origem** (ex: `e2`)
   - A **posição de destino** (ex: `e4`)
4. O sistema validará o movimento e atualizará o tabuleiro.
5. O jogo segue alternando entre as cores até o **xeque-mate**.
